# BINARY_SEARCH_ALGORITHM

## 📌 Description
This program demonstrates the Binary Search algorithm using Java.
Binary Search efficiently finds an element in a sorted array by repeatedly dividing the search space.

## ⚙️ Algorithm Used
- Binary Search (Iterative)

## ⏱ Time Complexity
- Best Case: O(1)
- Average Case: O(log n)
- Worst Case: O(log n)

## ▶️ How to Run
1. Compile:
   javac BinarySearch.java
2. Run:
   java BinarySearch

## 🎯 Use Case
Used in searching large datasets efficiently such as databases and sorted collections.
